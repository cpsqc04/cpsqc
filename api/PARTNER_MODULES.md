# AlertaraQC — Five Partner Modules (API Cheat Sheet)

Live catalog: `/api/partner-api.php`  
Full guide: `/api/API_INTEGRATION.md`

Base URL (local): `http://localhost/cpsqc-main`  
Production: `https://surveillance.alertaraqc.com`

**Share this link with partners:**
`https://surveillance.alertaraqc.com/api/partner-api.php`

**Inbound partner APIs are public** — only `Content-Type: application/json` is required. No API key.

Outbound (AlertaraQC → partners) still uses keys configured in `.env` when calling partner receive URLs.

Partner rename map (legacy names still accepted in code/env fallbacks):

| Preferred | Legacy |
|-----------|--------|
| **incident-reporting** | Group 1 |
| **emergency-response** | Group 3 |
| **crime-analytics** | Group 5 |
| **campaign** | Group 6 |
| **disaster-preparedness** | Group 8 |

## 1) Footage Request — INBOUND

Partners **send** footage requests into AlertaraQC.

| | |
|---|---|
| Endpoint | `POST /api/cctv_requests_receive.php` |
| Auth | Public (no API key) |
| List | `GET /api/cctv_requests.php` |

### Sample body
```json
{
  "agency": "Barangay Legal Office",
  "contact_number": "09181234567",
  "email": "legal@example.com",
  "case_reference": "CASE-2026-014",
  "purpose": "Investigation of reported disturbance",
  "legal_basis": "Community safety investigation",
  "incident_location": "Heavenly Drive, Brgy. San Agustin",
  "camera": "CAM-001",
  "footage_window": {
    "date": "2026-07-09",
    "start": "18:00",
    "end": "19:30"
  },
  "incident_description": "Reported disturbance near the gate",
  "delivery_method": "secure_download",
  "supporting_document": "",
  "review_notes": ""
}
```

`request_id` and `date_submitted` are generated by AlertaraQC.

## 2) Track Complaint

### OUTBOUND (AlertaraQC → Incident Reporting)
Triggered in admin **Track Complaint → Forward**.

| | |
|---|---|
| Partner URL env | `INCIDENT_REPORTING_API_URL` (legacy: `BLOTTER_API_URL`) |
| API key | `INCIDENT_REPORTING_API_KEY` (legacy: `BLOTTER_API_KEY`) |
| Payload builder | `includes/blotter_forward.php` |
| Local test receiver | `POST /api/blotter_receive.php` |

Fields sent: complainant name/address/contact, date & time, defendant name/address/contact, complaint type, specify type, status description, notes.

### INBOUND Status (Incident Reporting → AlertaraQC)

| | |
|---|---|
| Endpoint | `POST /api/complaints_status_receive.php` |
| Auth | Public (no API key) |

```json
{
  "complaint_id": "COMP-2026-001",
  "status": "Resolved",
  "notes": "Case closed in Digital Blotter"
}
```

Allowed status: `Pending`, `Processing`, `Resolved`, `Rejected`, `Forwarded to Digital Blotter`

## 3) Event List — INBOUND

| | |
|---|---|
| Endpoint | `POST /api/awareness_events_receive.php` |
| Auth | Public (no API key) |
| List | `GET /api/awareness_events.php?record_type=event` |

```json
{
  "record_type": "event",
  "source_group": "campaign",
  "event_id": "EVT-2026-014",
  "event_name": "Community Safety Awareness",
  "date": "2026-07-25",
  "time": "09:00",
  "venue": "Barangay San Agustin Hall",
  "organizer": "Maria Santos",
  "status": "Scheduled"
}
```

Aliases: `event_date`/`date`, `event_time`/`time`. If `event_id` is omitted, AlertaraQC generates one.

## 5) Review Tip — OUTBOUND

AlertaraQC **sends** tips to Incident Reporting when admin clicks send.

| | |
|---|---|
| Partner URL env | `INCIDENT_REPORTING_TIP_API_URL` (falls back to `INCIDENT_REPORTING_API_URL`; legacy: `TIP_BLOTTER_API_URL` / `BLOTTER_API_URL`) |
| API key | `INCIDENT_REPORTING_API_KEY` |
| Trigger | Admin Review Tip → Send to Incident Reporting (`api/send_to_incident_reporting.php`) |
| Local test receiver | `POST /api/tip_incident_receive.php` |

Outbound fields include: Tip ID, Date & Time, Location, Tip Description, Attached Evidence (photo), Status, Outcome.

Police backup uses **Emergency Response**:
| Partner URL env | `EMERGENCY_RESPONSE_API_URL` (legacy: `GROUP3_API_URL`) |
| API key | `EMERGENCY_RESPONSE_API_KEY` (legacy: `GROUP3_API_KEY`) |

## Quick local test (PowerShell)

```powershell
$headers = @{ "Content-Type" = "application/json" }
$body = @{
  agency = "PNP"
  contact_number = "09171234567"
  purpose = "Investigation"
  legal_basis = "Safety"
  incident_location = "Heavenly Drive"
  camera = "CAM-001"
  footage_window = @{ date = "2026-07-09"; start = "18:00"; end = "19:30" }
  incident_description = "Sample incident"
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Method POST -Uri "http://localhost/cpsqc-main/api/cctv_requests_receive.php" -Headers $headers -Body $body
```
